# 🏡 AI House Price Prediction

### Machine Learning | Python | Scikit-learn | Streamlit

## 1. Project Overview

AI House Price Prediction is a machine learning project designed to estimate residential property prices using data-driven techniques.

The project applies Python-based data analysis and machine learning to explore housing data, identify relevant patterns, and develop a predictive model for estimating house prices.

The application provides an interactive interface through Streamlit, allowing users to explore the house price prediction solution.

## 2. Project Objectives

- Explore and understand housing market data.
- Perform data cleaning and preprocessing.
- Identify important factors influencing house prices.
- Develop and evaluate machine learning models.
- Build an interactive house price prediction application.

## 5. Methodology

The project follows a structured machine learning workflow:

1. Data Collection: Obtain housing data for analysis.
2. Data Exploration: Examine distributions, patterns and relationships.
3. Data Preprocessing: Prepare the dataset for modelling.
4. Feature Engineering: Identify and prepare relevant predictive variables.
5. Model Development: Train machine learning models.
6. Model Evaluation: Assess predictive performance using appropriate evaluation metrics.
7. Deployment: Develop an interactive application using Streamlit.

## 6. Installation and Setup

Clone the repository:

```bash
git clone https://github.com/Gloria11242/AI-House-Price-Prediction.git
```

Navigate into the project directory:

```bash
cd AI-House-Price-Prediction
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```
